# 六十甲子太岁全谱与人物故事总集
## 文档说明
1. **权威依据**：以百度百科“六十甲子太岁”词条为基准，参校中国道教协会“六十元辰”体系及北京白云观元辰殿奉祀名录，统一名讳、朝代与核心事迹。
2. **版本规范**：太岁信仰在元明时期定型，本名录以“大将军”为统一尊号，异名（如“管仲”亦作“管敬仲”）在故事中备注，造像与法器采用道观主流形制。
3. **使用提示**：每一条目包含「干支/生肖/对应年份」「太岁名号」「形象与法器」「历史朝代与核心故事」，2026年为**丙午年**，值年太岁为**文哲大将军**。

## 第一部分：太岁信仰核心概述
太岁，亦称“岁君”“值年太岁”，源于中国古代天文历法中的“岁星纪年法”。古人假想与木星（岁星）运行方向相反、周期相同的“太岁星”，以六十甲子为循环，每年由一位太岁星君轮值，掌管当年人间吉凶、方位时序与祸福奖惩。

道教将六十甲子人格化为“六十元辰”，均为历史上忠良贤达之士，生前以德行、功业造福一方，死后被奉为太岁神，兼具“监察人间善恶”与“护佑本命元辰”的职能。民间“拜太岁”习俗，核心是敬奉值年太岁与本命太岁，以祈流年顺遂、趋吉避凶。
